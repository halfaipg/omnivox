Overview

This documentation provides details about the Omnivox Integration API, which allows you to interact with the Omnivox voice agent system. The API enables you to manage calls, voices, knowledge bases, calendar integrations, and more.

The API is designed to be used by developers who want to integrate Omnivox voice agents into their applications.

Authentication

Most API endpoints require authentication. You can authenticate by providing an API key in the X-API-Key header. 


fetch('/api/endpoint', {
  headers: {
    'X-API-Key': 'your-api-key-here'
  }
})

Incoming Call

POST /incoming

Handle an incoming call from Twilio or Telnyx.

Request Parameters

Parameter Description
CallSid* The Twilio Call SID or Telnyx Call Control ID
From* The caller's phone number
To* The recipient's phone number

Response

Returns TwiML or TeXML instructions for call handling.

Outgoing Call

POST /outgoing

Initiate an outgoing call.

Request Parameters

Parameter Description
to* The phone number to call
from The caller's phone number
voice The voice ID to use for the call
agent The agent's name
corpus The corpus ID to use for RAG

Response


{
  "call_id": "abc123",
  "status": "initiated"
}

Direct Connect

POST /direct-connect/:callId

Directly connect an Omnivox session to a call.

URL Parameters

Parameter Description
callId* The ID of the call to connect to

Request Parameters

Parameter Description
wsUrl* The WebSocket URL for the Omnivox session
sessionId* The Omnivox session ID

Response


{
  "success": true,
  "call_id": "abc123",
  "message": "Connected to call"
}

Call Status

POST /call-status

Receive call status updates from Twilio or Telnyx.

Request Parameters

Parameter Description
CallSid* The call SID or control ID
CallStatus* The current status of the call

Response

200 OK

Callback

POST /callback

Receive callbacks from Twilio or Telnyx.

Response

200 OK

WebRTC Join URL

POST /webrtc-join-url

Get a URL for joining a WebRTC call with Omnivox.

Request Parameters

Parameter Description
voice The voice ID to use
agent The agent's name
corpus The corpus ID for RAG
prompt The system prompt

Response


{
  "join_url": "wss://Omnivox-server.com/join/abc123",
  "session_id": "session-xyz"
}

Clone Voice

POST /clone-voice

Clone a voice from an audio sample.

Request Parameters (multipart/form-data)

Parameter Description
audio* Audio file to clone (MP3 or WAV)
name* Name for the cloned voice
gender Gender of the voice (male/female)

Response


{
  "success": true,
  "voice_id": "voice-789",
  "message": "Voice cloned successfully"
}

Calendar Availability

GET /api/calendar/availability

Get available time slots from Google or Microsoft Calendar.

Query Parameters

Parameter Description
startDate Start date for availability check (default: today)
days Number of days to check (default: 7)
provider Calendar provider (google or microsoft, default: google)

Response


{
  "success": true,
  "slots": [
    {
      "date": "2023-06-01",
      "day": "Thursday",
      "slots": [
        { "start": "09:00", "end": "09:30" },
        { "start": "10:00", "end": "10:30" }
      ]
    },
    {
      "date": "2023-06-02",
      "day": "Friday",
      "slots": [
        { "start": "11:00", "end": "11:30" },
        { "start": "14:00", "end": "14:30" }
      ]
    }
  ]
}

Schedule Event

POST /api/calendar/schedule

Schedule a new event on Google or Microsoft Calendar.

Request Parameters

Parameter Description
summary* Event title
startDateTime* Start date and time (ISO format)
endDateTime* End date and time (ISO format)
description Event description
attendees Array of email addresses for attendees
provider Calendar provider (google or microsoft, default: google)

Response


{
  "success": true,
  "event": {
    "id": "event123",
    "summary": "Product Demo",
    "start": "2023-06-01T09:00:00Z",
    "end": "2023-06-01T09:30:00Z"
  }
}

Microsoft Authentication

GET /auth/microsoft

Initiate Microsoft OAuth authentication flow.

Response

Redirects to Microsoft OAuth consent screen.

OAuth Callback

GET /oauth2callback-microsoft

Callback endpoint for Microsoft OAuth flow.

Query Parameters

Parameter Description
code* Authorization code from Microsoft

Response

Redirects to application with authentication result.

System Prompt

GET /system-prompt

Get the default system prompt used for Omnivox agents.

Query Parameters

Parameter Description
isOutbound Whether the prompt is for an outbound call (true/false)
agentName The name of the agent
userEmail The user's email address

Response


{
  "prompt": "You are an AI assistant named [agentName]. Your goal is to assist callers in a friendly and helpful manner..."
}
