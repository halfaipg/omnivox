Website with Voice Agent Widget Example

This is an example of how to embed the voice agent widget on your website. The widget appears in the bottom-right corner of this page.

Your Website Content

This could be any content on your website. The voice agent widget will appear as a floating element and won't interfere with your page layout.

Users can click on the widget to start a conversation with your AI assistant using their microphone.

The widget is fully customizable with different themes, positions, and avatar images.

How to Add This Widget

There are two ways to add the widget to your website:

Using Shareable URL
Direct Configuration

Simply add this single line of code to your website:

<script src="https://yourdomain.com/widget/embed.js?url=YOUR_SHAREABLE_URL"></script>

Replace YOUR_SHAREABLE_URL with the shareable URL from the voice agent interface.

Directly configure the widget with your desired parameters:

<script src="https://yourdomain.com/widget/embed.js?voice=YOUR_VOICE_ID&agent=AI%20Assistant&corpus=YOUR_CORPUS_ID&prompt=You%20are%20a%20helpful%20AI%20assistant"></script>

Parameters:

  • voice: The ID of the voice to use
  • agent: Name the agent will introduce itself as
  • corpus: ID of the knowledge base (optional)
  • prompt: System prompt for the agent's behavior
  • theme: 'light' or 'dark'
  • position: 'bottom-right', 'bottom-left', 'top-right', or 'top-left'
  • avatar: URL to an avatar image
